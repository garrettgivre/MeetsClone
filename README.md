# Tamagotchi Meets Clone

A browser-based virtual pet inspired by *Tamagotchi Meets* (Bandai, 2018).

## Concept

- **Raise a pet** through life stages: feed it, play with it, clean up after it, and put it to sleep.
- **Meet other pets** at a "meets" hub, make friends, and eventually find a partner.
- **Genetics:** a new generation mixes its parents' parts (head, eyes, mouth, body, color), so every family line looks different.
- **Generations:** your family tree carries on across generations.

## Tech

Plain HTML, CSS and JavaScript. No build step yet.

## Status

Project setup only. No game code has been written yet.
